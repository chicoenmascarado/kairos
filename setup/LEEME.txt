KAIROS — instalación en el ASUS ROG Strix G15 (G513IC)
======================================================

El USB (Ventoy) lleva:
  - Kairos-v0.x.iso     el sistema (Windows 11 Pro 25H2 adelgazado)
  - KairosSetup\        el post-install (se lanza solo)
  - $WinPEDriver$\      drivers del portátil (Windows los instala solo)
  - ventoy\             región, teclado y hora de España + arranque automático

1. INSTALAR
   - Portátil apagado y enchufado. USB puesto.
   - Enciende y pulsa ESC repetidamente -> elige el USB (UEFI).
   - En Ventoy elige la ISO de Kairos y, cuando pregunte, la plantilla
     "kairos-unattend.xml" (si eliges la otra opción, no se automatiza nada).
   - Borra todas las particiones del disco Intel de 512 GB y elige el espacio vacío.
     (Esto borra TODO lo que hay en el portátil.)
   - Crea tu usuario (cuenta local). No quites el USB.

2. SE TERMINA SOLO
   - Al entrar por primera vez se abre "Kairos Setup". Acepta el aviso de permisos
     y conéctate a internet cuando te lo pida. Tarda 15-30 minutos.
   - Hace: drivers · Windows en español · Visual C++ 2005-2022, DirectX y .NET 3.5
     (los piden FL Studio y muchos plugins) · plan de energía "Kairos Estudio" y
     ajustes de baja latencia · G-Helper para ASUS · la capa Kairos (dock, KaiSpot,
     menú, explorador, tema) · informe en el escritorio.
   - Al final pide una clave de Windows (opcional) y reiniciar. Ya puedes quitar el USB.
   - Si no se abriera solo: C:\Kairos\Setup\INSTALAR-KAIROS.cmd

3. PARA PRODUCIR
   - Instala FL Studio (image-line.com) y los drivers ASIO de tu interfaz de audio.
   - FL Studio > Options > Audio settings > tu interfaz ASIO (o "FL Studio ASIO").
   - Buffer: 128-256 para grabar, 512 para mezclar.
   - Si notas cortes: comprueba con LatencyMon (resplendence.com) y graba enchufado.
   - Las apps a pantalla completa apartan el dock; con FL maximizado queda justo encima.

ATAJOS DE KAIROS
   Alt+Espacio          KaiSpot: buscar apps, archivos, calcular
   Ctrl+Mayús+Espacio   Menú de Kairos
   Win+Alt+E            Explorador de Kairos
   Win+Alt+S            Captura de pantalla
   Win+Alt+V            Pegar como texto plano
   Win+Alt+RePág/AvPág/M  Volumen + / - / silencio
   Clic en la hora del dock: centro de control y bandeja del sistema.

ANTIVIRUS
   El informe del escritorio dice si el sistema lleva Windows Defender. Si pone
   "SIN ANTIVIRUS" (ISO v0.2), descarga programas y plugins solo de sus webs
   oficiales o instala un antivirus de terceros.

NOTAS
   - Windows Update sigue activo, pero no reinicia solo con la sesión abierta.
   - Si un plugin antiguo no carga su protección anticopia (iLok, etc.), se puede
     desactivar la Integridad de memoria (sube un poco el rendimiento) con un comando
     en una terminal de administrador y reiniciando:
       reg add HKLM\SYSTEM\CurrentControlSet\Control\DeviceGuard\Scenarios\HypervisorEnforcedCodeIntegrity /v Enabled /t REG_DWORD /d 0 /f
   - Registro de la instalación: C:\Kairos\setup.log
